# Manuscript results

`main_results.csv` transcribes Table I and `ablation_visdrone.csv` transcribes Table II from the latest submission manuscript, **LDC-YOLO: A Compact Detector for Small Objects in UAV Imagery** (local source revision dated 2026-09-21).

AP values are percentages. Parameters are in millions and FLOPs in billions at 640×640. Published comparison rows correspond to daggered entries in the manuscript. Ablations are cumulative; the three additions after the strong baseline total 2.2 AP50 percentage points.

These are paper-reported values. They are not new benchmark outputs from the first repository release.
